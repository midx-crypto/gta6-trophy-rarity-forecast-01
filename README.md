Forecasts every GTA VI PlayStation 5 trophy's Exophase earn rate one week after launch, as five quantiles per trophy, from the house's recorded reads up to the deadline. Per-trophy log-time trend extrapolation in logit space with a shrunk slope, plus a refresh-dilution mixture when the history shows no refresh at all: a refresh before the target dilutes rates as newly tracked players join.

## Run it

```sh
MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
